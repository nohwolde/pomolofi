# 📸 Screenshot Guide for README

This guide explains what screenshots to add to make the README look amazing.

## Required Screenshots

Create a `docs/images/` directory and add the following screenshots:

### 1. Banner (`banner.png`)
- **Size:** 1200x400px (or similar aspect ratio)
- **Content:** Hero shot of the app showing the main interface with:
  - Beautiful ambient scene background
  - Timer visible
  - Music player showing
  - Overall aesthetic of the app
- **Tip:** Use a visually striking scene like Starry Night or Magical Forest

### 2. Timer Feature (`timer-feature.png`)
- **Size:** 800x600px
- **Content:** Focus on the timer modal/interface showing:
  - Pomodoro timer settings
  - Start button
  - Time selection options
- **Tip:** Take screenshot when timer modal is open

### 3. Music Player (`music-player.png`)
- **Size:** 600x400px
- **Content:** Close-up of the music player showing:
  - Stream selection
  - Currently playing stream with album art
  - Volume controls
  - Custom video option
- **Tip:** Make sure a lofi stream is playing with visible artwork

### 4. Environments (`environments.png`)
- **Size:** 1000x700px
- **Content:** The environment selection modal showing:
  - Grid of live wallpaper previews
  - Grid of still image previews
  - Mouse hovering over one to show the effect
- **Tip:** Take screenshot when environment modal is open

### 5. Ambient Sounds (`ambient-sounds.png`)
- **Size:** 400x500px
- **Content:** The ambient sound player showing:
  - Available sound options (rain, fire, ocean)
  - Selected sound highlighted
  - Play/pause and volume controls
- **Tip:** Expand the sound player before screenshot

### 6. Task List (`tasks.png`)
- **Size:** 500x600px
- **Content:** Task panel showing:
  - Mix of completed and incomplete tasks
  - Add task button
  - Task counter
- **Tip:** Add a few sample tasks to show the interface

### 7. Focus Stats (`stats.png`)
- **Size:** 800x500px
- **Content:** Statistics panel showing:
  - Beautiful charts with data
  - Timeframe selector (Today/7 Days/28 Days)
  - Focus time, breaks, Pomodoros metrics
- **Tip:** Use demo data or actual stats from a week of usage

### 8. Notes (`notes.png`)
- **Size:** 700x500px
- **Content:** Notes panel showing:
  - Rich text editor interface
  - Some sample content formatted with markdown
  - Auto-save indicator
- **Tip:** Write some sample notes to showcase the editor

## How to Take Screenshots

### For macOS:
1. **Fullscreen:** `Cmd + Shift + 3`
2. **Selection:** `Cmd + Shift + 4` (drag to select area)
3. **Window:** `Cmd + Shift + 4`, then press `Space`, click window

### For Windows:
1. **Fullscreen:** `PrtScn` or `Win + Shift + S`
2. **Active Window:** `Alt + PrtScn`
3. **Selection:** `Win + Shift + S` (select area)

## Recommended Tools

- **macOS:** Built-in Screenshot app, or [CleanShot X](https://cleanshot.com/)
- **Windows:** Built-in Snipping Tool, or [ShareX](https://getsharex.com/)
- **Cross-platform:** [Flameshot](https://flameshot.org/)
- **Editing:** [Figma](https://figma.com) (free), Photoshop, or [Photopea](https://www.photopea.com/) (free online)

## Tips for Great Screenshots

1. **Use a clean browser window** - Hide bookmarks bar, extensions, etc.
2. **Consistent sizing** - Try to keep similar dimensions across related screenshots
3. **Show real content** - Use actual data/tasks instead of empty states when possible
4. **Good lighting/contrast** - Make sure text is readable
5. **Highlight key features** - Focus on what makes each feature special
6. **Use the app in production mode** - `npm run build && npm start` for the cleanest UI
7. **Consider adding annotations** - Use arrows or highlights to point out key features (optional)

## File Format

- **Format:** PNG (best for UI screenshots)
- **Compression:** Use [TinyPNG](https://tinypng.com/) to reduce file size while maintaining quality
- **Max size:** Try to keep each image under 500KB for faster README loading

## Alternative: Video Demo

Instead of (or in addition to) screenshots, consider creating a short demo video:

- **Length:** 30-60 seconds
- **Content:** Quick walkthrough of main features
- **Format:** MP4 or GIF
- **Tool:** [Loom](https://loom.com), [Screen.Studio](https://screen.studio), or [Kap](https://getkap.co/)
- **Add to README:** Upload to YouTube or host as GIF

---

Once you've created these screenshots, simply place them in the `docs/images/` directory and the README will automatically display them! 📸✨
